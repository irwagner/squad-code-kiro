# CLAUDE.md

> Este projeto foi migrado do **Claude Code** para o **Kiro CLI** (`kiro-cli`).
> A orientação para trabalhar neste repositório agora está em:
>
> - **`KIRO.md`** — guia do repositório (comandos, build, como o Kiro é dirigido).
> - **`AGENTS.md`** — contexto de produto e diretrizes dos agentes.
> - **`.kiro/agents/README.md`** — presets de squad (dev, SaaS, labs, pentest) e modelo de segurança.
>
> Este arquivo é mantido apenas como ponteiro. O recurso de **exportar uma operação como subagentes do Claude Code**
> (`.claude/agents/*.md` + `CLAUDE.md`) continua existindo na UI para quem usa o Claude Code — ele gera um `CLAUDE.md`
> dentro da pasta exportada, independente deste arquivo.
